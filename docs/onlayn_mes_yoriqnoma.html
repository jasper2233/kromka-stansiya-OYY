Joriy qilish yo'riqnomasi

Onlayn MES — stansiyani avtomatik sozlash

Monoblok yoqilganda o'zi ochiladi, Pico ga o'zi ulanadi, sozlamalarni MES dan o'zi oladi. Operator hech narsa bosmaydi.

1 Qanday ishlaydi

Monoblok yoqiladi
  → Windows avtomatik login
  → Chrome kiosk rejimida ochiladi:
      https://mes.korxona.uz/stansiya?station=KROMKA-01
  → Sahifa ?station dan o'zini taniydi
  → GET /api/settings?station=KROMKA-01  → kalibrlash, dopusklar
  → navigator.serial.getPorts()  → Chrome siyosati bilan oldindan ruxsat berilgan
  → Pico ga o'zi ulanadi, SET yuboradi
  → Har 60 s: sozlamalar qayta so'raladi, o'zgargan bo'lsa Pico ga yuboriladi
  → Hodisalar: IndexedDB navbat → POST /api/events  (tarmoq uzilsa saqlanadi)

Stansiya sahifasi MES serverning o'zidan beriladi. Monoblokda hech qanday fayl yo'q — faqat Chrome va bitta URL.

4 Chrome siyosati — Serial portga avtomatik ruxsat

Bu eng muhim qadam. Usiz operator har yoqilganda "Pico ga ulanish" tugmasini bosib, portni tanlashi kerak bo'ladi.

Windows da administrator sifatida cmd oching va bitta buyruq bajaring. Domenni o'zingiznikiga almashtiring:

reg add "HKLM\Software\Policies\Google\Chrome" /v SerialAllowUsbDevicesForUrls /t REG_SZ /d "[{\"devices\":[{\"vendor_id\":11914,\"product_id\":5}],\"urls\":[\"https://mes.korxona.uz\"]}]" /f

11914 = 0x2E8A — Raspberry Pi vendor ID, 5 — MicroPython CDC product ID. Ya'ni ruxsat faqat Pico ga va faqat sizning domeningizga beriladi.

Tekshirish: Chrome da chrome://policy oching, SerialAllowUsbDevicesForUrls ko'rinishi kerak. Ko'rinmasa Chrome ni to'liq yopib qayta oching.

Edge uchun Yo'l boshqacha: HKLM\Software\Policies\Microsoft\Edge, qolgani bir xil.

5 Kiosk avtostart

  1. Bat fayl yarating — masalan C:\stansiya\start.bat: 
    @echo off
timeout /t 15 /nobreak >nul
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --app="https://mes.korxona.uz/stansiya?station=KROMKA-01" --no-first-run --disable-features=TranslateUI --disable-session-crashed-bubble --overscroll-history-navigation=0
    15 soniya kutish — tarmoq va USB tayyor bo'lishi uchun.
  2. Avtostartga qo'ying. Win+R → shell:startup → ochilgan papkaga start.bat ning yorlig'ini tashlang.
  3. Avtomatik login. Win+R → netplwiz → "Foydalanuvchilar parol kiritishi shart" belgisini oling → operator hisobini tanlang.
  4. Uyqu va qulfni o'chiring. Sozlamalar → Tizim → Quvvat → ekran va uyqu "Hech qachon". Shaxsiylashtirish → Qulf ekrani → ekran taymeri o'chiq.
  5. Windows Update ni cheklang. Sozlamalar → Yangilanish → Faol soatlar: smena vaqti. Aks holda tunda qayta yuklanib, ertalab login oynasida turadi.
Kiosk dan chiqish Alt+F4 yoki Ctrl+Shift+W. Texnik xizmat uchun. Agar operator chiqib ketmasligi kerak bo'lsa — Windows "Assigned Access" (Sozlamalar → Hisoblar → Boshqa foydalanuvchilar → kiosk o'rnatish) — unda Chrome dan boshqa hech narsa ochilmaydi.

6 MES tomonida kerakli API

Stansiya sahifasi to'rtta endpoint bilan ishlaydi. Sinov serveri (mes_server.py) ularning aynan shu shaklini beradi — haqiqiy MES ham shunday bersa, sahifa o'zgarishsiz ishlaydi.

GET /api/part?qr=A-1001

200 → {"code":"A-1001","name":"Yon panel","L":800,"W":600,"need":"2,2"}
404 → {"error":"topilmadi"}

GET /api/settings?station=KROMKA-01

{"station":"KROMKA-01",
 "kal":{"D":2003.4,"V10":9.87,"V18":17.92,"K":1.18,"TD":3},
 "tol":{"detal":3},
 "updated":"2026-09-09T14:22:10"}

updated — o'zgarish belgisi. Sahifa har 60 soniyada so'raydi; farq bo'lsa yangi qiymatlarni Pico ga yuboradi. MES da sozlamani o'zgartirish = stansiyani masofadan sozlash.

POST /api/settings

← {"station":"KROMKA-01","kal":{...},"tol":{...}}
→ {"ok":1,"updated":"2026-09-09T14:22:10"}

7 Xavfsizlik

  • Token. Har stansiyaga o'z tokeni. MES uni X-Station-Token sarlavhasidan tekshiradi. Bekor qilinsa — stansiya hech narsa yubora olmaydi.
  • Mantiq serverda. Monoblokda faqat brauzer. Kalibrlash, dopusk, detal ro'yxati — hammasi MES da. Nusxa olinadigan narsa yo'q.
  • Serial ruxsati faqat Pico ga (VID/PID bilan) va faqat sizning domeningizga. Boshqa sayt portga kira olmaydi.
  • Operator hisobi administrator emas. Chrome siyosatini o'zgartira olmaydi, dastur o'rnata olmaydi.

8 Tekshiruv ro'yxati

  1. Brauzerda https://mes.korxona.uz/stansiya?station=KROMKA-01 ochiladi, qulf belgisi yashil.
  2. chrome://policy da SerialAllowUsbDevicesForUrls ko'rinadi.
  3. Sahifa yuklanganda Pico chipi o'zi yashil bo'ladi — tugma bosilmaydi.
  4. "Sozlama" chipida vaqt ko'rinadi — MES dan yuklandi.
  5. MES da dopuskni o'zgartiring → 60 soniyada stansiya chipi yangilanadi.
  6. Tarmoq kabelini uzing, detal o'tkazing → "navbat: 1". Ulang → 3 soniyada "navbat: 0".
  7. Monoblokni qayta yuklang → 1–5 qadamlar o'zi takrorlanadi.
